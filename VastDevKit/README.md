# VastDevKit

An engine for building VR applications. This directory is a source snapshot in
the vastvr repository, alongside VastApps.

From the repository root:

```sh
./scripts/build-macos.sh Debug VastDevKit
```

Box2D and difont (including FreeType) are vendored source snapshots. There is no
submodule initialization step. See the [root README](../README.md) and
[third-party notices](../THIRD_PARTY_NOTICES.md).
